# Moneo

A modern personal finance management application for tracking money, understanding spending, managing budgets and reaching savings goals.

## Tech Stack

- **Frontend:** React, TypeScript, Vite, TanStack Router, TanStack Query, shadcn/ui
- **Backend:** C#, ASP.NET Core, REST API
- **Database:** PostgreSQL
- **Testing:** xUnit, Integration Testing, Playwright

# High Level Architecture

Client (React) ---HTTP---> Backend (ASP .NET CORE) -> Database (PostgreSQL)
